# SmartExam

AI-powered Online Examination Platform built with Django.

## Features

- Role-based Authentication
- Exam Management
- Subject Management
- Chapter Management
- Question Bank
- PDF Question Import
- Excel Question Import
- Mock Tests
- Student Dashboard
- Teacher Dashboard
- Analytics

## Tech Stack

- Python
- Django
- PostgreSQL
- AWS
