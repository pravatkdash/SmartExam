# SmartExam Version 2 (Future Enhancements)

## Assessment

### Shuffle Questions

#### Problem
Teachers may want students to receive questions in different orders to reduce copying during online exams.

#### Proposed Solution
Add a new configuration to Assessment.

```python
shuffle_questions = models.BooleanField(
    default=False,
)
```

#### Behavior

- Preserve the teacher's original question order.
- Shuffle questions only while displaying the assessment to students.
- Never modify the stored order in the database.


#### Example

Teacher Order

1. Cell Structure
2. Cell Division
3. Genetics
4. Photosynthesis

Student A

1. Genetics
2. Cell Structure
3. Photosynthesis
4. Cell Division

Student B

1. Photosynthesis
2. Genetics
3. Cell Division
4. Cell Structure
